Rotas da API

Todas as rotas /api/* exigem o header Authorization: Bearer <token>. A rota /healthz é pública.

GET/healthz
Público — status do serviço.
GET/api/config
Token — modelo, URL do drive e paralelismo máximo.
GET/api/ready
Token — se o modelo está carregado (200) ou ausente (503).
POST/api/chat
Token — corpo: {"messages":[{"role":"user","content":"…"}]}. Rate limit: 12/min.
Configuração
Usado para /healthz, /api/config, /api/ready e /api/chat.
